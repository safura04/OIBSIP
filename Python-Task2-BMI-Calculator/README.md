# BMI Calculator

## Oasis Infobyte Internship – Python Task 2

A graphical Body Mass Index (BMI) Calculator developed using Python and Tkinter.

## Features

- Accepts height in meters and weight in kilograms
- Calculates BMI using the standard formula
- Displays the BMI value and corresponding category
- Validates invalid, empty, zero, and negative inputs
- Includes Calculate and Reset buttons
- Provides a simple graphical user interface

## Technologies Used

- Python
- Tkinter

## Formula

BMI = Weight (kg) / Height (m)²

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run:

   `python bmi_calculator.py`

## BMI Categories for Adults

- Below 18.5: Underweight
- 18.5–24.9: Normal Weight
- 25.0–29.9: Overweight
- 30.0 and above: Obesity

BMI is a screening measure and is not a diagnosis of health.
